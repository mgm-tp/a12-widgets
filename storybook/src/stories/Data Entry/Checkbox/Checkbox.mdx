The `Checkbox` widget wraps the native HTML checkbox input and adds a label, tooltips and
validation messages. It is a controlled component: pass the current value via `checked` and
update your state in `onChange(value, event)`.

- Supports `disabled` and `readonly` states.
- The `error`, `warning` and `info` flags combine with `errorMessage`, `warningMessage` and
  `infoMessage` to show validation hints below the checkbox.
- For tri-state selection (e.g. a "select all" parent), use the separate `IndeterminateCheckbox`
  widget, which accepts `checked: "mixed"`.
