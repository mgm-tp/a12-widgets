The `TagInput` widget is a tag editor that lets the user create and remove multiple tags inside a
single input field, using both mouse and keyboard. Tags are created by typing text and pressing one
of the configured trigger characters (`keys`, comma by default).

- `popularTags` are offered in a dropdown when the input is focused (controlled via `openOnFocus`);
  `suggestionTags` are matched against the text the user is typing.
- Duplicate tags are rejected with a localized message, overridable via `duplicatedTagMessage`.
- `onAddedTag` and `onRemoveTag` report every change; `comparator` controls the sort order of tags.
- Supports the common input states: `label`, `helperText`, `errorMessage`, `disabled` and `readonly`.
