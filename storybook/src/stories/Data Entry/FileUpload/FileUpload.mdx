The `FileUpload` widget lets users upload files either by opening the native file picker or by
dragging and dropping files onto the upload area. `DefaultFileUpload` is the styled default
implementation with preview icons, loading state and a file link display.

- Use `onChange` to receive the chosen `FileList`; it also tells you whether the file was dropped.
- After an upload, pass `fileOptions` to display the chosen file as a link with an optional icon.
- `loading` together with `loadingLabel` and `onCancel` covers the in-progress upload state.
- `compact` renders a single-line variant for dense forms; `multiple` and `accept` map to the
  native file input attributes.

## Keyboard navigation

The stories under `FileUpload/KeyboardNavigation` cover focus behavior: by default **Tab** focuses
the upload area and **Enter** / **Space** opens the file picker; with
`KeyboardNavigationConfigProvider` set to `arrow-only`, **Tab** skips the widget and arrow keys
navigate within it.
