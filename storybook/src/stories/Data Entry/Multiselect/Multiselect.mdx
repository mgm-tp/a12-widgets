The `Multiselect` widget combines a text-field input with a dropdown of checkable options, letting
users pick multiple values from a list. Typing into the input filters the available options, and the
selected items are displayed in the input as a comma-separated list (customizable via `joiningHandler`).

- The dropdown offers an optional "select all" entry (`enableSelectAllOption`, `selectAllText`) and an
  informational hint above the options (`hintTemplate`, e.g. `"{count} of {total} options shown"`).
- Selection is controlled by the consumer: pass `items` with `selected: true` flags and update them in
  the `onChange` callback, which reports the full set of selected items.
- Filtering, sorting and grouping of options can be customized with `filteringHandler`,
  `sortingHandler` and `groupingHandler`; `mobile` renders the selection as a modal instead.
- Validation feedback is shown below the input via `errorMessage`, `warningMessage` and `infoMessage`.
