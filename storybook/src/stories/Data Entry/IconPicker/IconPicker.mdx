The `IconPicker` widget is a text-field-based input for selecting a Material icon. Typing in the
input filters the icon list by name; the matching icons are shown in a dropdown together with a
hint line driven by `hintTemplate` (e.g. `"{count} of {total} icons shown"`). Use it wherever
users need to attach an icon to an entity, such as configuring menu entries or categories.

- Selection is reported through the required `onChange` callback, which receives `undefined` when the clear button is clicked; `onIconClick` fires for clicks on individual icons.
- The dropdown opens on focus by default (`openOnFocus`).
- `saveSpaceMode` hides the icon labels in the list; the picker also enables this automatically when it is narrower than 208px.
- As a text-field-based input, it supports `label`, `placeholder`, `helperText`, `disabled` and `readonly`.
