The `DefaultRichTextEditor` widget is a form field for entering and formatting rich text, built on
the [Lexical](https://lexical.dev/) editor framework. It supports bold, italic, underline, lists and
text alignment via a configurable toolbar, and shares the common input field anatomy (`label`,
`helperText`, `errorMessage`, `disabled`, `readonly`).

- Compose the toolbar with `staticToolbarButtons` from items like `BoldButton`, `ItalicButton`, `BulletListButton`, `AlignButtonGroup` and `Separator`.
- Control sizing with `minHeight`, `maxHeight` and `autoExpand`, or use `singleLine` for a compact one-line field.
- Subscribe to content changes via `onChange`, which receives the Lexical `EditorState` and editor instance.
- The editor requires its CSS theme: `import "@com.mgmtp.a12.widgets/widgets-core/styles/rich-text-editor.css";`

## Keyboard navigation

The sidebar entry **RichTextEditor/KeyboardNavigation** demonstrates the two focus modes: in the
default mode **Tab** moves through the toolbar and editor areas, while the arrow-only mode (enabled
via `KeyboardNavigationConfigProvider`) keeps toolbar navigation on **← / →** and lets **Tab** skip
the whole editor.
