The `Select` widget wraps the native HTML select element and adds a label, placeholder,
helper text and validation messages. Use it whenever the user has to pick exactly one
value from a predefined list of options.

- `items` accepts flat options or groups (entries with `children` render as option groups).
- `error`, `warning` and `info` flags pair with `errorMessage`, `warningMessage` and `infoMessage` for validation feedback.
- `useCustomView` (or the `CustomSelect` widget) swaps the native select for a custom dropdown that supports rich item rendering and opens a modal picker on mobile devices.
