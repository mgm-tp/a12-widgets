The `Autocomplete` widget provides autocompletion for enumerated values, combining a text field for
input with a dropdown for selecting from the matching options. While the user types, the first
matching option is pre-selected and the remaining characters of that option are highlighted inline.

- Options starting with the entered text are listed first, and a `hintTemplate` shows how many options match.
- A clear button (toggle with `enableClearButton`) resets the current value — handy on touch devices.
- Use `allowAddingNewItem` to let users submit values that are not in the `items` list.
- For asynchronous sources, filter via `onSearch` and show a progress indicator with `loading`.
- On phones the options are presented in a fullscreen dialog, where an attached dropdown would sit
  behind the on-screen keyboard. `mobileModal` pins either presentation regardless of the device.
- Long match lists are windowed automatically, from 150 matches, so only the options in view are
  rendered; `virtualize` forces that on or off.
