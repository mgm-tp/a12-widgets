The `Switch` widget is a binary toggle input for turning a single setting on or off, typically
with immediate effect. It is a controlled component: pass the current state via `checked` and
update it in the required `onChange` handler.

- Optional `checkedOption`/`uncheckedOption` labels make the current state explicit; hide them with `hideOptions`.
- The label can be placed on any side of the control via `labelPosition` (`top`, `left`, `right`, `bottom`).
- Supports the shared input states (`disabled`, `readonly`, `error`, `warning`, `info`) with matching messages and `helperText`.
- The thumb icons can be customized with `checkedIcon` and `uncheckedIcon`.
