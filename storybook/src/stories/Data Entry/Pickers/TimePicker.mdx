The `TimePicker` widget combines a text input with a clock-style popup for selecting a time.
Users can either type a time directly — validated via `onValidate` — or pick hours and minutes
on the clock face.

- `mode` switches between the `12h` and `24h` clock; the mode can also be inherited
  application-wide from `DateTimeContext` (`timeMode`).
- `value`/`onChange` control the selected time; `timeFormatter` and `timeConverter` customize
  how the input text is rendered and parsed.
- A `timezone` (IANA database name) can be provided so times are interpreted in that zone.
- On touch devices the picker opens in a modal dialog (`okLabel`, `clearLabel`,
  `customHeaderTitle` customize it).
