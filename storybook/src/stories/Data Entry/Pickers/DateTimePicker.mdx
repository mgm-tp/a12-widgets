The `DateTimePicker` widget combines the `DatePicker` calendar with a time screen, letting users
pick a date and a time in a single flow. It extends `DatePickerProps` (react-day-picker), so
`disabled` matchers, `modifiers`, `yearRange` and the `yearSelectorVariant` header all apply here too.

- A value is confirmed via `onAccept`; `onChange` reports every intermediate date/time change.
- `timeMode` switches the clock between `12h` and `24h`; `timeRequired` makes picking a time mandatory.
- `initialScreen` (`date`, `time`, `hour`, `minute`) controls which screen opens first; headers,
  footers and the time-edit element can be replaced via `customHeaderElement`, `customFooterElement`
  and `customTimeEditElement`.

For a picker attached to a text input, wrap it with the `DateTimePickerInput` higher-order
component (see the [Input integration](#input-integration) section below).
