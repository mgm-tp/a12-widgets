`DateTimePickerInput` is a higher-order component that attaches a text input to a
`DateTimePicker` (or to `DateTimePickerTimeInput`, a picker variant with a dedicated time input
on the time screen). Users can type a date and time directly or open the picker popup from the
input's button.

- The wrapped picker is configured through `pickerProps` (everything `DateTimePicker` supports:
  `timeMode`, `timezone`, `disabled` matchers, `yearRange`, …).
- Typed input is parsed with `dateTimeInputFormat` or fully custom
  `dateTimeFormatter`/`dateTimeConverter` functions; invalid input is reported via
  `onInputValidationError` and surfaced with `inputErrorMessage`.
- `inputLabel`, `placeholder`, `helperText`, `inputWarningMessage` and `inputTooltips` cover the
  usual form-field anatomy.

The controls in the Playground map to picker props and are forwarded via `pickerProps`.
