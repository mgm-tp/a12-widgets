The `DatePicker` widget renders an inline calendar for selecting a single date or a date range.
It is built on top of react-day-picker, so its props extend `DayPickerProps` — including
`disabled` day matchers, `modifiers` and custom styling per day.

- The calendar header offers month navigation plus a configurable year selector
  (`yearSelectorVariant`: `select`, `textbox` or `autocomplete`, constrained by `yearRange`).
- Single-date selection uses `value`/`onChange`; range selection uses `selected`/`onDateRangeChange`
  together with the `footer` accept/clear buttons.
- A `timezone` (IANA database name) can be provided so dates are interpreted in that zone.

For a date picker attached to a text input, use the `DateInput` widget shown in the
[Input integration](#input-integration) section below.

## Input integration

The `DateInput` widget combines a text field with the `DatePicker` in a popup, including input
parsing (`dateConverter`), formatting (`dateFormatter`) and validation errors. See the
`DatePicker/Input` sidebar entry for all variants (disabled, readonly, input-only, range input).
