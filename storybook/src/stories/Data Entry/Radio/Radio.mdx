The `Radio` widget wraps native HTML radio inputs in a group and adds a group label, tooltips,
validation states and messages. Use it whenever the user must pick exactly one option from a small
set of mutually exclusive choices.

- Options are declared as `Radio.Item` children, each with a `label` and a `value`.
- The group is controlled: the selected item is set via `value` and changes are reported through
  `onValueChanged`.
- `inline` switches from the default vertical stack to a single row.
- `disabled` and `readonly` apply to the whole group; a single `Radio.Item` can also be disabled
  individually.
