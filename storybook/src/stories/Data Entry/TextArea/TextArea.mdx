The `TextAreaStateless` widget wraps the HTML `textarea` element and adds a label, validation
messages, helper text, prefixes/suffixes and addons. Use it for multi-line free-text input such as
descriptions, comments or notes.

- Fully controlled — pass `value` and update it in `onChange`; the widget keeps no intrinsic state.
- Use `error`/`warning` together with `errorMessage`/`warningMessage` for validation feedback.
- Use `autoExpand` to let the field grow with its content instead of scrolling.
