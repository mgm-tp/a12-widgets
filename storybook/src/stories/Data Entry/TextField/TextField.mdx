The `TextField` widget wraps the HTML input element and extends it with a label, helper text,
validation states, tooltips and prefix/suffix slots. It has no intrinsic state — control it via
`value` and `onChange`.

- Use `label` (with optional `hideLabel`) and `helperText` to describe the field.
- `error`, `warning` and `info` flags plus their `*Message` props communicate validation results.
- `prefixes`/`suffixes` place icons or text inside the input; `addonBefore`/`addonAfter` place
  elements next to it.
- `disabled` and `readonly` cover the non-editable states; `textAlignment` supports right-aligned
  numeric input.
