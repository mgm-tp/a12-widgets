The `YearMonthSelector` widget combines a month selector and a year selector into a single labelled
form field. Use it when only a month/year value is needed — e.g. credit card expiry dates or
reporting periods — instead of a full date picker.

- `month` uses a zero-based index (0 = January); changes are reported via `onValueChange(month, year)`.
- The embedded year selector supports three rendering modes via `yearSelectorVariant` (`select`,
  `textbox`, `autocomplete`); when omitted, the mode is auto-detected from `yearRange`.
- `invalidComponent` controls whether the `year`, the `month` or `both` selectors are marked invalid
  in an error state.
- Provide `hiddenLabels` so screen readers can name the two individual selectors.
