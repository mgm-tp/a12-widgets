The `Icon` widget wraps an HTML `<i>` element and renders the [Material Symbols](https://fonts.google.com/icons)
icon named by its `children`. Use it wherever a small pictogram is needed — standalone, inside buttons,
menus or status messages.

- `iconTheme` switches between the `filled` (default), `outlined` and `rounded` Material Symbols styles, or `custom` for project-specific icons.
- `title` provides a tooltip and an accessible name; `hiddenText` overrides the screen-reader text, and `showTitleAsTooltip` suppresses the tooltip while keeping the name readable by assistive technology.
- `size` (`medium`/`big`) controls the font-size, `variant` (`info`/`success`/`warning`/`error`) applies a semantic color, and `onClick` makes the icon react to mouse clicks.
