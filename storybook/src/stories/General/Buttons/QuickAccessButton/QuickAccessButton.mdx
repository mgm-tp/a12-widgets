The `QuickAccessButton` widget is a split button: it combines a `mainAction` button with a trigger
button that opens a popup menu of related secondary actions (`actionItems`). Use it when one action
is the common default (e.g. "Save") but users occasionally need close variants of it (e.g. "Save and
close").

- The trigger button supports the standard button variants `primary`, `secondary`, `destructive`, `invert` and `disabled`.
- `menuTriggerIcon` replaces the default trigger icon; `onVisibilityChange` notifies about popup open/close.
- By default focus returns to the trigger button after the popup closes (`focusOnTriggerElementAfterClose`).

## Keyboard navigation

The sidebar entry **KeyboardNavigation** demonstrates the two keyboard modes: in the default mode
**Tab** moves between the main action and the dropdown trigger, while the `arrow-only` mode (via
`KeyboardNavigationConfigProvider`) makes the whole widget a single tab stop navigated with arrow
keys.
