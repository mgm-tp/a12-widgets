The `ButtonGroupContainer` widget is a layout component that wraps multiple buttons and positions
them in left- and right-aligned groups. Use it for toolbars and action bars where related actions
belong together.

- Pass buttons either directly as `children` or declaratively via `leftSlotButtons` / `rightSlotButtons` (accepting `ButtonProps` or `QuickAccessButtonProps`).
- With `responsive` enabled, buttons that do not fit into the available width are collapsed into a popup menu; `collapsingDirection` controls which side collapses first.
- `preserveSemanticStyles` keeps `primary` / `destructive` / `disabled` styling on the collapsed popup menu entries.

## Keyboard navigation

The `KeyboardNavigation` sidebar entry demonstrates the two keyboard navigation modes: the default
mode (**Tab** / **Shift+Tab** and **← / →** move between visible buttons) and the arrow-only mode
configured via `KeyboardNavigationConfigProvider`, where **Tab** skips the entire group.
