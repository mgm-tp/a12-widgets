The `ButtonGroup` widget is a specialized layout container that wraps multiple buttons and
positions them together with consistent spacing. Use it wherever related actions appear side by
side, such as form footers or toolbars.

- Use `alignment` (`left` or `right`) to float the group inside a surrounding `Clearfix`;
  right-aligned groups should come after left-aligned ones in the DOM so the tab order matches
  the visual order.
- Use `vertical` to stack the buttons in a column instead of a row.
