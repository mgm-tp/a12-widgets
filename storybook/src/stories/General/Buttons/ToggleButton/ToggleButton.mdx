The `Toggle` widget renders a group of mutually exclusive options as connected buttons. It is a
controlled component: pass the selected item's value via `value` and react to clicks with
`onValueChanged(newValue, oldValue)`.

- Options are declared as `Toggle.Item` children, each with a required `value` and arbitrary content (text, `Icon`, …).
- `disabled` and `readOnly` can be set on the whole toggle or on individual items.
- `showOnlySelectedOption` collapses the group to the selected item until hovered; the item-level `variant` (`status1`–`status3`) colors the selected-item overlay in this mode.
- Wrap the toggle in an `InteractionHintConfigProvider` to show each item's `title` as a hover hint.
