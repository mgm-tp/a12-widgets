The `Button` widget wraps the native HTML button element and adds the A12 button styles plus extra
functionality such as icons, badges and loading progress. It is the default trigger for actions
throughout the platform.

- Pick a style with the boolean props `primary`, `secondary` and `destructive`; `disabled` works with all of them.
- Set `icon` without a `label` to get an icon button — always add a `title` for accessibility.
- Use `loading` with `processedPercentage` to show progress for long-running actions.
- Use `invert` on dark backgrounds, `block` to fill the parent and `labelHidden` to keep the label accessible while hiding it visually.
