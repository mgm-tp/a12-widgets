The `PopUpMenu` widget displays a trigger button (a three-dot icon by default) that opens a floating
menu when clicked. Use it for repeated row/card actions or as a collapsed menu when space is limited,
typically with a `List` of items as content.

- The trigger can be customized via `icon` or fully replaced via `triggerElement`.
- The popup positions itself relative to the trigger; `orientation` sets the preferred placement.
- Escape and outside clicks close the menu (`closeOnEsc`, `closeOnOutsideClick`), and focus is
  managed for you: `focusOnOpen` moves focus into the popup, `focusOnTriggerElementAfterClose`
  returns it to the trigger.
- `triggerButtonTitle` / `triggerButtonCloseTitle` provide a localized accessible name for the
  default trigger button.

## Keyboard navigation

The `KeyboardNavigation` sidebar entry demonstrates the two keyboard navigation modes: the default
mode (Tab moves through the open menu, arrow keys move between items) and the `arrow-only` mode
configured via `KeyboardNavigationConfigProvider`, where Tab skips over the open menu entirely.
