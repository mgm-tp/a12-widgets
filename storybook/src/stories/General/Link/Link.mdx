The `Link` widget renders a styled anchor element for navigating to documents, resources or
locations via `href`. It supports `title` tooltips, a `target` to control where the destination
opens, and an `onClick` handler.

- Set `useAsButton` when the link triggers an interactive function instead of navigating — it adds `role="button"` for better semantics.
- Pass extra native anchor attributes (e.g. `aria-disabled`) through `linkAttributes`.
- When wrapped in an `InteractionHintConfigProvider`, hovering the link shows an interaction hint based on its `title`.
