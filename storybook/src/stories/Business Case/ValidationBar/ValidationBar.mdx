The `ValidationBar` widget summarizes validation results — errors, warnings or informational
notices — in a prominent bar, typically shown above a form or business document. It announces the
overall validation state and gives users a starting point to resolve the reported issues.

- The `variant` prop (`error`, `warning`, `info`) selects the severity styling; `error` is the default.
- `primaryTitle` carries the main message, with an optional `secondaryTitle` below it and an `icon` in the header.
- `quickAccessMenu` and `pagination` add controls for stepping through individual validation issues.
- The bar receives focus on mount by default (`autoFocus`) so screen-reader users are notified immediately.

## Keyboard navigation

The keyboard navigation stories demonstrate how focus moves through the validation bar: by default
**Tab** steps through each action button, while `KeyboardNavigationConfigProvider` with
`validationBar: "arrow-only"` switches to **← / →** navigation inside the bar so **Tab** skips it
entirely.
