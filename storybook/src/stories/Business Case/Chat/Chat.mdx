The `Chat` widget is a compound component for building chat UIs. `Chat.Container` is the scrollable
message area — it keeps the view pinned to the newest message and exposes scroll callbacks
(`onScroll`, `onScrollStart`, `onScrollEnd`) for implementing features like loading older messages.

- Group consecutive messages from one user with `Chat.MessageGroup`; its `position` (`left`/`right`)
  aligns the whole group.
- Render individual messages with `Chat.Message`; the `status` prop shows metadata such as
  timestamps or read receipts below the bubble.
- Identify the sender via `Chat.UserInfo` with an optional `Chat.Avatar` (falls back to a generic
  account icon).
- Structure the stream with `Chat.DateMarker`, announce events inline with `Chat.Notification`, and
  signal activity with `Chat.TypingMarker`.
