The FacetedSearch widgets let users narrow down result sets with removable filter chips. `Filter`
renders a single chip with a `name`, optional `options` values and a close button (`onClose`);
`FilterBar` is the responsive container that lays the chips out and collapses overflowing ones
behind an expand/collapse button. A separate `FilterSelector` panel is available for picking which
filters to apply.

- `active` filters get a highlighted left border; inactive ones are dimmed.
- `FilterBar` reports responsively hidden chips via `onHiddenFiltersChange` and can start collapsed
  with `initialCollapsed`.
- Use `nonRemovable` for mandatory filters and `compact` for dense layouts.
