The `Comment` widget renders a single comment with avatar, author information, body text and
optional nested replies. Use it for discussion threads, review feedback or activity streams.

- `commentMeta` supplies avatar, author, action and date; `inactiveCommentMeta` replaces it while `inactive` is set.
- `actionButtons` (or `combinedActionButton` with a `PopUpMenu`) attach contextual actions such as reply, edit or delete.
- `replies` nests further `Comment` elements styled via `isReply`; `commentTags` adds categorisation chips.
- Use `CommentList` for a list of comments and `CommentContainer` for the floating panel pattern.

## Keyboard navigation

The action buttons of a comment support two keyboard navigation modes: by default **Tab** moves
through each button, while `KeyboardNavigationConfigProvider` with `{ comment: "arrow-only" }`
switches to arrow-key navigation so **Tab** skips the whole comment. See the
`Comment/KeyboardNavigation` sidebar entry for both modes.
