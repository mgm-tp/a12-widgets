The `MessageBox` widget shows a prominent message to the user — typically validation results,
errors, warnings or confirmations — with an optional `icon`, an optional `action` element on the
right of the header and additional content below the `label`.

- Four color schemes via `variant`: `info`, `success`, `warning` and `error` (default).
- By default the box receives invisible focus after rendering (`focusOnMessage`), so screen readers announce it immediately.
- Use the `action` slot for a button that expands or collapses detail content.
