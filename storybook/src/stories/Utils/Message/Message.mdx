The `Message` widget is a themed container for short inline text messages within a layout, such as
hints, notes or explanatory text next to other content. Its color, typography and padding come from
the theme (`theme.components.message`), so messages look consistent without custom styling.

- Accepts arbitrary `children` — plain text as well as formatted inline elements.
- Purely presentational: it carries no severity or icon. For status messages with severity levels,
  use the `MessageBox` or `GlobalMessageBox` widgets instead.
