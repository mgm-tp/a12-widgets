The `LinesEllipsis` widget clamps multi-line text to a maximum number of lines and renders an
ellipsis at the truncation point. Unlike pure CSS line clamping, it measures the text with
JavaScript, which allows a custom `ellipsis` node, precise truncation `basedOn` letters or words,
and an `onReflow` callback reporting whether the text was actually clamped.

- `maxLine` controls how many lines are allowed (default `1`).
- `responsive` (default `true`) re-computes the truncation whenever the container is resized.
- `htmlSupport` enables experimental truncation of HTML content.
