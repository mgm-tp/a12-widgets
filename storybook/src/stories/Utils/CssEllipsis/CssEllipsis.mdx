The `CssEllipsis` widget truncates overflowing text with an ellipsis using performant CSS line
clamping. Use it wherever long, user-generated content must fit a constrained layout, such as
table cells, cards or list items.

- Use `maxLine` to clamp the content to a fixed number of lines.
- Without `maxLine`, the line count is calculated automatically — the parent element must have a
  fixed height for this to work.
- Use `useTooltip` to reveal the full content on hover; `tooltipVariant` selects the tooltip style.
