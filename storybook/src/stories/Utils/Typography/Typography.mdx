The `Typography` widget provides structured heading and body text building blocks for page layouts.
`Typography.Headline` renders a heading at a styling `level` (1–5) and supports dividers, collapsible
sections, info indicators, addons and header action buttons. `Typography.Body` renders paragraph-level
text, and `Typography.Section` groups headlines and body text into a structured section.

- `level` controls styling only — use `ariaLevel` or `htmlTag` to set the semantic heading level.
- `collapsible` together with `collapsed` / `onCollapsingChange` turns a headline into a section toggle.
- `info`, `addons` and `headerActions` place supplementary content and actions in the headline row.

## Keyboard navigation

Collapsible headlines are keyboard accessible: **Tab** reaches the headline, **Enter** / **Space**
toggles the section and **Tab** continues to any header action buttons. With
`KeyboardNavigationConfigProvider` set to `arrow-only`, **↑ / ↓** move between the headline and its
header actions while **Tab** skips the whole section. See the `KeyboardNavigation` sidebar entries
for both modes.
