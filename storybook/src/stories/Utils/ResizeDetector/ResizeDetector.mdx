The `WidgetsResizeDetector` widget is a thin wrapper around the library's own `useResizeObserver`
hook, making element resize observation usable in class components. Pass a
`targetRef` pointing at the element to observe and an `onResize` callback that receives the latest
`width`, `height` and `ResizeObserver` entry whenever that element changes size.

- It renders only its `children` — no extra wrapper element is added to the DOM.
- `handleWidth` / `handleHeight` select which dimension changes trigger the callback.
- `refreshRate` debounces the notifications. `refreshMode` and `refreshOptions` are deprecated and
  ignored — notifications are always debounced.
