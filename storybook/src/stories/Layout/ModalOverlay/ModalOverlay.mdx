The `ModalOverlay` widget displays content in a dialog on top of the current page, blocking
interaction with everything behind it. Use it for confirmations, focused forms or any task that
requires the user's full attention before continuing.

- Closing is controlled by the consumer: render the modal conditionally and pass `onClose`; enable
  `closeOnEsc` and/or `closeOnOutsideClick` to let users dismiss it.
- Focus is managed automatically — the modal is focused on open (`focusOnOpen`) and focus returns
  to the trigger element on close (`focusBack`).
- Size it with `maxWidth` (pixels or a string like `"70%"`), make it `fullscreen`, or constrain it
  to its parent with `fitToParent`.
- Avoid `closeOnOutsideClick` when the modal contains other portals (e.g. `Select`, `DatePicker`),
  as clicks inside them count as outside clicks.
