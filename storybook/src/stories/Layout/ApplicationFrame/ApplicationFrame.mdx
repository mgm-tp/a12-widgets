The `ApplicationFrame` widget is the responsive top-level layout of an A12 application. It arranges
an application header (`main`), an optional collapsible sidebar (`sub`), the `content` area and an
optional `footer`, and adapts to desktop, tablet and smartphone screen sizes.

- On desktop the sidebar sits next to the content; on tablet it partially overlaps it; on
  smartphones it is hidden initially and can be opened via a toggle (`useToggleButton`).
- Sidebar expansion is controlled with `subExpanded` / `onExpansionChange`, and the expanded
  sidebar can be `minimized` or `maximized` via `subExpandedState`.
- `subToolbar` and `contentToolbar` add toolbars above the sidebar and the content, and
  `subResizableOptions` lets users resize the boundary between sidebar and content.
