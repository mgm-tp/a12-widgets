The `SplitView` widget divides the available horizontal space into side-by-side
`SplitView.Area` regions. Use it for multi-pane layouts such as navigation / content / details
views where each pane manages its own content.

- Areas without a `width` share the remaining space equally; `width` (pixels or any CSS length) makes an area fixed-size.
- Pass `resizableOptions` (with required `minWidth` and `maxWidth`) to let users drag an area's edge to resize it; `onResizeStop` reports the final width.
- A lone area expands to the full width and hides its resize handle automatically.
