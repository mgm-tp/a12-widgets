The `MasterDetail` widget arranges content panes in a responsive master/detail layout, such as a
list of records next to the details of the selected record. Each pane is described by a
`VisibleView` entry with a `key`, an `element` and an optional `width` based on a 12-column grid.

- Designed to be responsive across desktop, tablet and smartphone — on small screens a single
  full-width pane is shown at a time.
- Changing the set of `visibleViews` animates the pane transition; configure or disable this via
  the `animation` prop.
- Panes can be made resizable through `resizableOptions` per view, or `firstViewResizableOptions`
  for the first pane only.
