The `ResizeHandler` widget attaches a draggable resize handle to a target element so users can
adjust its width with the mouse — typically for side panels in split layouts. Pass a ref to the
element you want to resize via `targetRef` and wrap that element as a child of the handler.

- `minWidth` and `maxWidth` clamp the resizable range; `resizable={false}` disables dragging.
- `position` controls which edge gets the handle (`right` by default) — place it at the boundary between the two panels.
- `onResizeStart`, `onResize` and `onResizeStop` report the drag lifecycle with the element's current dimensions.
