The `ResizeAndDragContainer` widget renders a floating panel that users can freely drag around
the screen and resize by its edges and corners. Use it for detail panels, tool palettes or
auxiliary views that should stay visible while the user keeps working underneath.

- Anchored to a `referenceElement` on initial mount; `orientation` (or `orientationList`) picks the starting position.
- `initialSize` sets the starting dimensions; `minWidth`/`minHeight`/`maxWidth`/`maxHeight` constrain resizing, and `disableResizing` turns it off entirely.
- Closes via `closeOnOutsideClick` and `closeOnEsc` (calling `onClose`); after ESC, focus returns to the reference element by default.
