The `CollapsiblePanel` widget renders a panel with a clickable header that expands or collapses
to show or hide its content. Use it to group secondary or optional content that users can reveal
on demand, e.g. in forms or settings pages.

- The panel is **controlled**: it is expanded while `children` are rendered and collapsed otherwise.
  `onClick` fires when the header is clicked or Enter is pressed — toggle your own state there.
- `info` appends plain text next to the title; `addons` places interactive elements in the header
  (optionally swapped with the indicator icon via `swapAddonsPosition`).
- `role` and `ariaLevel` allow tuning the header semantics for accessibility, and an open/close
  interaction hint can be enabled via `InteractionHintConfigProvider`.
