The `ResponsiveImageContainer` widget renders an image that automatically scales to fit its
parent container while preserving its aspect ratio (via `object-fit: contain`). Use it whenever
an image must adapt to a layout slot of unknown or changing size — cards, previews, galleries.

- The image never exceeds the parent's width or height; wide and tall images both scale down proportionally.
- Provide `alt` text for accessibility; it defaults to an empty string.
- `onClick` and `onLoad` callbacks let you react to user interaction and successful loading.
- The legacy `handleHeight` and `preferWidth` props are deprecated — sizing is handled purely in CSS.
