The `ActionContentbox` widget structures content and actions in a consistent way: a header
(heading, notification area, subheading with action buttons), a content area and an optional
footer. Use it as the standard container for views, forms and detail pages.

- Compose the heading from `ContentBoxElements` building blocks: `Title`, `Subtitle`, `BackButton`, `CloseButton`, `Footer`.
- Action buttons passed via `buttons` render in an action bar and collapse into a popup menu when space is tight (compact mode).
- `padding`, `embedded` and `boxShadow` control how the box fits into its surroundings.
