The `Callout` widget is a floating container anchored to a `referenceElement`, used to surface
contextual content without leaving the current screen — helping you use screen space effectively
and reduce clutter.

- Renders next to its anchor and repositions according to the `orientationList`.
- Closes on outside click, Escape or clicking the reference element again — each behavior can be
  disabled via `closeOnOutsideClick`, `closeOnEsc` and `closeOnClickReferenceElement`.
- Supports an optional `header` (with `prefix`, `title` and `suffix`), a `footer` for actions, a
  pointer arrow (`isPointerVisible`) and configurable content `padding`.
- Can be made resizable and draggable via `resizeAndDragOptions`.
