The `InteractionHint` widget is a tooltip-like overlay that shows the `title` of a reference
element on hover or focus. It is anchored to the trigger element via `referenceElementRef` and
rendered in a portal, so it is not clipped by overflowing containers.

- The `variant` prop colors the hint as `hint`, `success`, `warning` or `error`.
- `position`, `followCursor` and `hideArrow` control where and how the hint is shown.
- `showDelay` controls how long the hint waits before appearing on hover, in milliseconds (default `500`).
- `InteractionHintConfigProvider` enables and configures the hints built into other widgets
  (buttons, links, menus, …) globally via `enableInteractionHint` and `componentConfigs`.
