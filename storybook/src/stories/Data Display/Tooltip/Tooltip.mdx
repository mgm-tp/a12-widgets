The `Tooltip` widget wraps a single child element and shows a short `text` when the user hovers
over or focuses the element on desktop, or touches it on mobile devices. Use it to provide extra
context for icons, buttons, links or form labels without cluttering the layout.

- `text` accepts any `ReactNode`, so tooltips can contain structured content as well as plain strings.
- `variant` (`success`, `hint`, `warning`, `error`) colors the bubble for semantic feedback.
- `invert` adjusts the trigger style of variant tooltips for dark backgrounds, and `useDesktopView`
  forces the desktop presentation on mobile devices.
- `showDelay` and `hideDelay` tune the hover timing in milliseconds (default `200` each). `TooltipConfigProvider`
  applies them to every tooltip in a subtree.
