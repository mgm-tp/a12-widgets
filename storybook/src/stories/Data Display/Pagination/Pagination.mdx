The `Pagination` widget renders page navigation controls — first, previous, next and last — plus a
dropdown to jump directly to a page. It is a controlled component: pass the `currentPage` and update
it in the `onPageChanged` handler.

- `pageLabelTemplate` formats the page label, e.g. `"Page {page} of {total}"`.
- Use `type="simple"` for a compact previous/next-only variant.
- `nextButtonProps` and `previousButtonProps` allow customizing the navigation buttons.
