The `BulletList` widget renders semantic HTML lists with consistent theming. It is a compound
component: `BulletList.Unordered` (`<ul>`) and `BulletList.Ordered` (`<ol>`) act as containers
for `BulletList.Item` (`<li>`) children.

- Unordered lists support the marker types `disc`, `circle`, `square` and `none`; ordered lists
  support `decimal`, `decimal-leading-zero`, `lower-roman`, `upper-roman` and `lower-alpha`.
- Use `inline` to lay items out horizontally, e.g. for navigation-style lists.
- Unordered lists can drop their default left indentation via `indent={false}`.
- Lists can be nested to any depth, mixing ordered and unordered levels.
