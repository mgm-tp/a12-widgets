⚠️ **Deprecated since v38.1.1.** `BarChart`, `LineChart` and `PieChart` are thin wrappers around
[Recharts](https://recharts.github.io/) and are deprecated — use Recharts directly in new code. See the
migration guide in the showcase under _Get Started → Migration Instructions → Chart Widgets to Recharts_.

The widgets configure the underlying Recharts elements through prop maps: `BarChart` takes a
`barPropsMap` keyed by `dataKey`, `LineChart` takes a `linePropsMap`, and `PieChart` takes `pieProps`.
Common options such as `showLegend`, `showTooltip`, axis labels (`xAxisLabel`/`yAxisLabel`) and
`cartesianGridProps` mirror the corresponding Recharts components. The charts fill their parent
container, so wrap them in an element with an explicit width and height.
