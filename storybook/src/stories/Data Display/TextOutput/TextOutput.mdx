The `TextOutput` widget displays a read-only value with an optional `label`, styled consistently
with the form input widgets. Use it to present stored data in detail views or read-only forms.

- Supports validation-style `errorMessage`, `warningMessage` and `infoMessage` between label and value.
- `tooltips` and `addonAfter` attach tooltips and addons to the label or content.
- `noData` renders a muted placeholder for missing values; `alignment` controls text alignment.
- Set `disableParagraphWrapping` when rendering inside table cells to avoid redundant paragraph semantics.
