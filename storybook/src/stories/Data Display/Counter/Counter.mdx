The `Counter` widget displays a numeric (or textual) value inside a pill-shaped element. Use it
inline to show quantities such as unread messages, result counts or task totals.

- Use `overflowCount` to cap large values, rendering e.g. `99+` instead of the raw number.
- The `type` prop (`default`, `constructive`, `destructive`) and the `secondary` flag control the color scheme.
- `addonBefore` / `addonAfter` place an icon or element next to the value, and `placeholder` is shown when `value` is undefined.
- For accessibility, `hiddenDescription` adds screen-reader-only context, and `title` plus `interactive` enable hover hints.

## Interaction hints

When wrapped in an `InteractionHintConfigProvider` with the `counter` config enabled, an
`interactive` counter shows its `title` as a tooltip on hover. See the `Counter/Interactions`
sidebar entry for more configurations such as `followCursor`.
