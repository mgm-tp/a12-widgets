The `Status` widget displays a short, color-coded status message, optionally preceded by an icon.
Use it to communicate the state of a record or process inline — for example "under review",
"completed" or "failed".

- The `variant` prop (`info`, `success`, `warning`, `error`) controls the color scheme; `info` is the default.
- Pass any element as `icon` — typically an `Icon` matching the variant's meaning.
- When the message wraps onto multiple lines, the icon aligns to the top of the text automatically.
