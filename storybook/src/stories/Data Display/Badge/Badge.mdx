The `Badge` widget displays a small count indicator, typically anchored to the corner of another
element such as an icon or button. Use it to signal unread items, pending tasks or status counts.

- Anchored by default — place it inside a `position: relative` container next to the element it annotates.
- Use `standalone` to render it as a regular inline element instead.
- Use `tiny` for a plain dot marker without a count.
