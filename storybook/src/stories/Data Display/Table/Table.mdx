The `Table` widget renders tabular data from a `data` array and a declarative `columns` definition
(`label`, `dataKey`, `width`, `sortable`, `pinning`, ...). It is the foundation for data-heavy
screens and scales from a simple read-only listing to fully interactive setups.

- Rows can be made selectable and styleable via `rowStyling` and `rowEventHandlers`; cells via `cellStyling`.
- Columns support sorting (`sortOptions`), pinning, grouping with `subColumns` and interactive resizing (`columnResizingOptions`).
- Every visual part can be overridden through `componentRenderers` — body content, footer, filter row, context menus and more.
- Large datasets are covered by `virtualScrollOptions` (windowed rendering) and `infiniteScrollOptions` (batched loading).
- Keyboard users can navigate cells with the arrow keys; turn this off with `disableArrowNavigation`.
