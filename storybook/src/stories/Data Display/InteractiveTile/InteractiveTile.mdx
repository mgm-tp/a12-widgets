The `InteractiveTile` widget is a clickable tile that presents arbitrary content — typically an icon
plus a short label — and reacts to mouse and keyboard interaction. Use it for option grids,
navigation entry points or selectable cards.

- `primary` and `secondary` select the visual style; without either flag the tile is styled as secondary, and `active` highlights it.
- `selected` shows a checkmark in the top-right corner — combine it with `onClick` for controlled single or multi selection.
- `disabled` blocks all mouse and keyboard interaction.
- The `title` prop is shown on hover and can be surfaced as a tooltip via `InteractionHintConfigProvider`.
