The `Calendar` month view supports continuous scrolling through weeks via `infiniteScrollOptions`,
turning the month grid into a virtualized, endlessly scrollable calendar between `minDate` and
`maxDate`. Use it when users need to browse events across many months without page-by-page
navigation.

- Data is loaded on demand: `dateLoadingStatus` reports per-day loading state and `loadData` fetches
  new ranges as the user scrolls (`threshold` controls how many extra weeks to prefetch).
- `displayWeeksCount` sets how many weeks fit in the viewport; `onVisibleRangeChange` reports the
  currently visible date range.
- `scrollToDate` provides a handler for programmatic navigation (e.g. "Today" buttons), and
  `weekScrollSnapType: "mandatory"` snaps scrolling to week boundaries.
