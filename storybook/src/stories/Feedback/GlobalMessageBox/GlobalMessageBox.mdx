The `GlobalMessageBox` widget displays a prominent, application-wide notification bar, typically
placed above the application header. Use it for messages that affect the whole application, such as
maintenance announcements, session warnings or critical errors.

- The `variant` prop (`info`, `success`, `warning`, `error`) controls the color scheme and default icon.
- `actions` renders elements on the right side — typically inverted buttons for follow-up or dismiss actions.
- `ellipsis` (default `true`) truncates the content to a single line.
- `focusOnMount` (default `true`) moves invisible focus to the box when it appears, so screen readers
  announce it; disable it on all but one box when several are shown at once.
