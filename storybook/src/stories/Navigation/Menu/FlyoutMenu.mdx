The `FlyoutMenu` widget renders a navigation menu either as a horizontal bar (`type="horizontal"`,
e.g. an application header) or as a vertical sidebar (`type="vertical"`). Nested `items` open as
flyout submenus on hover, click or keyboard interaction, with `hoverDelay` controlling how quickly
hover opens them.

- Items support `icon`, `badge`, `counter`, `selected`, `disabled`, `variant` status icons and an
  `onClick` handler; `MenuGroup` entries group items in horizontal menus.
- A vertical menu can be compacted to icons only via `collapsed`.
- When a horizontal menu runs out of space, overflowing items condense into a three-dot item
  (`onCondensed` reports them, `condensedBadge` decorates the three-dot item).
- `useAs` ("main" or "tabNavigation") and `mainContainerLabel` control the menu's semantics and
  accessible name.

The `Interactions` and `InteractionsAdvanced` sidebar entries demonstrate `InteractionHintConfigProvider`
with the FlyoutMenu: enabling hints for horizontal/vertical menus, `followCursor`, `hideArrow` and the

## Keyboard navigation

The `KeyboardNavigation` sidebar entry demonstrates the default keyboard navigation mode (Tab and arrow
keys move between items, Enter opens a submenu, Escape closes it) and the `arrow-only` mode configured
via `KeyboardNavigationConfigProvider`, where Tab skips past the entire menu.
