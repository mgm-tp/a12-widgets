The `ApplicationHeader` widget renders a banner bar at the top of the page for displaying the
application logo, application name, version or user information. Content is passed through two
slots that accept any `ReactNode`:

- `leftSlots` — typically the application logo, name or a hamburger menu in mobile mode.
- `rightSlots` — typically version info, the user name, action buttons or a popup menu when
  horizontal space is limited.
- The header element uses the ARIA `role` `"banner"` by default; it can be overridden via the
  `role` prop.
