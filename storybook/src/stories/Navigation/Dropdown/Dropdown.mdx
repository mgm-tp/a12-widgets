The `DropDown` widget renders an open list of selectable items — it is the selection panel used as
a building block for select boxes, autocomplete fields and similar overlays. Selection is fully
controlled: pass the current `selectedItem` and react to `onSelectedItemChange`.

- Items are plain `DropDownItem` objects and support `disabled`, `isEmptyValue`, a `graphic`
  element, a `secondaryText` line and grouping via `children`.
- The list is keyboard-accessible: Arrow keys move the pre-selection, Enter (configurable via
  `keysToSelectItem`) selects the pre-selected item.
- Use `hint` to announce how many items match a search, `lightBackground` on light surfaces,
  `horizontal` for toolbar-style layouts and `footer` for extended functionality such as loading
  more items.
- `selectionMode="multiple"` makes it a multi-select listbox: it renders the checkboxes, states each
  option's selection, toggles instead of replacing, and reports the result through
  `onSelectionChange`. An option carries the value it stands for as `data`, and `getItemKey`
  identifies it.
- `virtualize` renders only the options in view, for lists long enough that rendering all of them
  would be felt. Sections are windowed along with their options.
- `useDropdownNavigation` holds the active option outside the list, for a combobox whose field keeps
  the focus — the list is handed the result as its `navigation` prop.
