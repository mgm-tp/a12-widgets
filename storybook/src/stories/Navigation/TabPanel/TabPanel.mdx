The `TabPanel` widget renders an icon-based tab list next to a content panel and is typically used
as a main navigation area, e.g. inside an application frame sidebar. Selection is controlled: pass
the active tab via `value` and update it in the `onSelect` callback.

- `tabs` accepts a flat `TabProps[]` list or a grouped `GroupTabProps[]` list; individual tabs can
  be `disabled`, `highlighted` or carry extra content such as a `Badge` (link it via `ariaLabelledby`).
- `orientation` switches between the default vertical sidebar layout and a horizontal tab bar.
- An optional `header` (e.g. `TabPanelTemplate.PanelHeader`) is rendered above the tab content.
- Accessibility: the tab list exposes a localized `aria-label` (overridable via `tabListAriaLabel`),
  and `focusOnPanelAfterSelect` moves focus to the panel after a tab is selected.
