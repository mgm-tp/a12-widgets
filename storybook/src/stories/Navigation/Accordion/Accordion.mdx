The `Accordion` widget creates vertically stacked sections that can be expanded and collapsed to
show or hide their content. It is composed from `Accordion.Container`, `Accordion.Section`,
`Accordion.Summary` (the clickable header) and `Accordion.Details` (the collapsible body).

- Sections manage their own expanded state by default; use `expanded` on a section to open it initially.
- Set `controlled` on the container to drive each section's `expanded` state yourself via the section `onClick` handler.
- Customize the expand/collapse icons per container or per section, add a `graphic` icon to a summary, or use a summary `variant` (`open`, `info`, `error`, `warning`, `done`, `inProgress`) to display a status icon.
