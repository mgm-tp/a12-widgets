The `Breadcrumb` widget displays the user's location within a page hierarchy as a trail of
`Breadcrumb.Item` elements, each typically wrapping a `Link`. Use it on pages nested more than one
level deep so users can navigate back to any ancestor in a single click.

- Renders as a `navigation` landmark with a localized `aria-label`.
- Mark the last item with `currentPage` — it receives `aria-current="page"` plus hidden
  screen-reader text and is usually plain text instead of a link.
- Items are divided by a `chevron_right` icon by default; pass any `ReactNode` via `separator` to
  customize the divider.
