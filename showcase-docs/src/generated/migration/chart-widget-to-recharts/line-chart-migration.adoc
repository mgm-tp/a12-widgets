= Line Chart Migration

When migrating from the Line Chart Widget to direct usage of Recharts, certain deprecated APIs and types need to be replaced with their corresponding Recharts components and properties.

== Deprecated APIs and Their Recharts Equivalents

Below is a mapping of deprecated APIs to their Recharts equivalents for Line Chart.

[cols="1,1",options="header"]
|===
| Deprecated API | Recharts Equivalent
| cartesianGridProps | link:https://recharts.github.io/en-US/api/CartesianGrid/[<CartesianGrid />]
| xAxisProps | link:https://recharts.github.io/en-US/api/XAxis/[<XAxis />]
| xAxisDataKey | link:https://recharts.github.io/en-US/api/YAxis/#dataKey[<XAxis dataKey />]
| xAxisLabel | link:https://recharts.github.io/en-US/api/XAxis/#label[<XAxis label />]
| yAxisProps | link:https://recharts.github.io/en-US/api/YAxis/[<YAxis />]
| yAxisLabel | link:https://recharts.github.io/en-US/api/YAxis/#label[<YAxis label />]
| tooltipProps | link:https://recharts.github.io/en-US/api/Tooltip/[<Tooltip />]
| linePropsMap | link:https://recharts.github.io/en-US/api/Line/[<Line />]
| legendProps | link:https://recharts.github.io/en-US/api/Legend/[<Legend />]
| thresholdLineProps | link:https://recharts.github.io/en-US/api/Area/[<Area />] and wrapped by link:https://recharts.github.io/en-US/api/ComposedChart/[<ComposedChart />]
| comparableAreaProps | link:https://recharts.github.io/en-US/api/Area/[<Area />] and wrapped by link:https://recharts.github.io/en-US/api/ComposedChart/[<ComposedChart />]
| showLegend | link:https://recharts.github.io/en-US/api/Legend/[<Legend />]
| showAndHideLines | link:https://recharts.github.io/en-US/api/Line/[<Line />]
| onLegendClick | link:https://recharts.github.io/en-US/api/Legend/#onClick[<Legend onClick />]
| onDotClick | link:https://recharts.github.io/en-US/api/Line/#activeDot[<Line activeDot />]
|===

For the complete list and documentation of all Recharts Line Chart components, please refer to the link:https://recharts.github.io/en-US/api/LineChart/[LineChart API].

== Deprecated Types and Their Recharts Equivalents

And below is a mapping of deprecated type to its Recharts equivalents for Line Chart.

[cols="1,1",options="header"]
|===
| Deprecated type | Recharts Equivalent
| LegendProps | link:https://recharts.github.io/en-US/api/Legend/[<Legend />]
|===

*NOTE:* Some Widgets' custom elements, such as Line Chart template's `+Legend+` and `+Item+` are also deprecated. Therefore, relying solely on Recharts may not provide the same result.
If you still wish to implement these functionalities, please refer to the Widgets core's existing implementation to apply the necessary customizations in your project.

== Migration Example

This is a practical example of how to migrate from the legacy Line Chart Widget.

* *Before:* Single component with properties
+
[source,tsx]
----
import { ResponsiveContainer, LineChart } from "@com.mgmtp.a12.widgets/widgets-core";

const DATA = [
	{ name: "A", desktop: 170 },
	{ name: "B", desktop: 150 },
	{ name: "C", desktop: 140 },
	{ name: "D", desktop: 125 },
	{ name: "E", desktop: 100 }
];

const LINE_PROPS_MAP = {
	desktop: {
		dataKey: "desktop",
		stroke: "#0088FE",
		strokeWidth: 2
	}
};

<ResponsiveChartContainer aspect={0.5} maxHeight={300}>
	<LineChart data={DATA} xAxisProps={{ dataKey: "name", tick: false }} linePropsMap={LINE_PROPS_MAP} />
</ResponsiveChartContainer>;
----
* *After:* Composed components with children from Recharts directly
+
[source,tsx]
----
import { ResponsiveContainer, LineChart, XAxis, YAxis, Line, Tooltip } from "recharts";

const DATA = [
	{ name: "A", desktop: 170 },
	{ name: "B", desktop: 150 },
	{ name: "C", desktop: 140 },
	{ name: "D", desktop: 125 },
	{ name: "E", desktop: 100 }
];

<ResponsiveContainer aspect={0.5} maxHeight={300}>
	<LineChart data={DATA}>
		<XAxis dataKey="name" tick={false} />
		<YAxis />
		<Tooltip />
		<Line dataKey="desktop" stroke="#0088FE" strokeWidth={2} />
	</LineChart>
</ResponsiveContainer>;
----
