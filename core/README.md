# A12 Widgets Core

This package contains A12 widgets.

### Supported Browsers

#### Desktop

- Latest Firefox
- Latest Firefox ESR
- Latest Chrome
- Latest Edge

#### Mobile

- Latest Chrome Android
- Latest Safari on iOS

## How to Build and Run

### Prerequisites

The following tools are required in order to build this repository:

| Tool                        | Version |
| --------------------------- | ------: |
| [Node](https://nodejs.org/) |  `24.x` |
| [pnpm](https://pnpm.io/)    |  `10.x` |

### Scripts

All necessary scripts for development are accessible by:

```sh
pnpm run <script>
```

In order to get a list of all scripts use:

```sh
pnpm run
```

### How to Build

You can run

```sh
pnpm compile
```

to compile the project.

### How to Run

Start compilation in watch mode:

```sh
pnpm start
```

### How to Test

You can run

```sh
pnpm test
```

to run all test cases, the project will be written to the `TEST-com.mgmtp.a12-widgets.xml` file.
