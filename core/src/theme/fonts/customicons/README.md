# custom-icons font

`custom-icons.woff` is the icon font behind the `CUSTOM_ICONS` code points in
`core/src/icon/main/custom-icons-data.ts`. It is generated with
[IcoMoon](https://icomoon.io/app/) (see the `name` table: _"Font generated by IcoMoon."_).

## Adding or changing an icon

1. Import the existing font into IcoMoon, add/replace the glyph, keep the code points of all
   existing icons untouched (they are public API), and export the `woff`.
2. **Normalize the glyph bounding boxes** (see below).
3. Register the new code point in `core/src/icon/main/custom-icons-data.ts`.

## Why the bbox normalization step

IcoMoon exports can contain `glyf` entries whose stored per-glyph bounding box does not match the
actual outline. Firefox validates and repairs them at load time and logs one warning per glyph into
the console of every application that loads the font:

```
downloadable font: glyf: Glyph bbox was incorrect; adjusting (glyph 31)
(font-family: "custom-icons" style:normal weight:400 stretch:100 src index:0)
```

Rendering is unaffected — Firefox uses the corrected box — but the warning is pure noise for
consumers. Recomputing the boxes before committing the font removes it. With
[fonttools](https://fonttools.readthedocs.io/) installed (`pip install fonttools`):

```python
from fontTools.ttLib import TTFont

font = TTFont("custom-icons.woff")
glyf = font["glyf"]
modified = font["head"].modified            # keep the export timestamp -> reproducible output
for name in font.getGlyphOrder():
    glyph = glyf[name]
    if glyph.numberOfContours:
        glyph.recalcBounds(glyf)
font.recalcBBoxes = True
font.flavor = "woff"
font.save("custom-icons.woff")

font = TTFont("custom-icons.woff")
font["head"].modified = modified
font.recalcTimestamp = False
font.save("custom-icons.woff")
```

Only the `glyf`/`head` bounding boxes change; outlines, `cmap`, `hmtx` and the `name` table stay
byte-identical. To verify, load the font and compare `glyph.xMin/yMin/xMax/yMax` against a fresh
`glyph.recalcBounds(glyf)` — the difference must be empty.
